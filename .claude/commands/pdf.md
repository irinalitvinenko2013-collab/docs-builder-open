Запусти сборку документа целиком, без подтверждений по мелочам (см. `CLAUDE.md`).

0. **Профиль.** Нет ни одного профиля — не берись за работу: сначала `/setup` (система должна
   знать, чей это документ). Профилей несколько и активный не назван — спроси одной фразой,
   в каком работаем. Профиль один — молча работай в нём.
1. **Слаг.** Придумай короткое имя работы (`<slug>`) и веди все свои файлы под ним:
   `ingest/normalized-<slug>.md`, `guide-<slug>.html`, `output/<Понятное-Имя>.pdf`,
   `qa-<slug>/`. В общие пути без слага не пиши — рядом может идти другая работа.
2. **Источник.** Текст, статья, готовая расшифровка → нормализуй сам. Ссылка, чужой PDF,
   запись голоса или встречи, скринкаст → субагент `source-extractor`.
3. **План страниц.** Разложи содержимое по страницам, назначь баланс тёмных/светлых 30/70
   и **запиши план в `ingest/<slug>-план.md`** — по нему верстает `pdf-builder`, по нему же
   приёмщик потом сверяет замысел с результатом. Не спрашивай — решай.
4. **Вёрстка.** Субагент `pdf-builder`: `guide-<slug>.html` → рендер → само-QA.
   Инструкция со скриншотами — он же дополнительно берёт `.claude/rules/learning-guide-spec.md`.
5. **Итог.** Верни путь к PDF и метрики: страниц, баланс, кликабельных ссылок, картинок.
   Что не получилось (нет ключа для картинок, ссылка не открылась, кадров меньше шагов) —
   назови прямо, а не умолчи.
